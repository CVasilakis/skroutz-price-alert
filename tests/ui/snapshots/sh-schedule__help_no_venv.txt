Usage: schedule.sh [-h] [--<target> ...]

Apply each scraper's configured execution interval to its systemd timer. The
interval is read from the "settings.execution_interval" field of the scraper's
config file (config/<target>.json) and translated to the timer's schedule. With
no target flag every installed scraper is updated; pass one or more --<target>
flags to update only those.

Supported intervals: unavailable (run ./install.sh first)
Many spellings are accepted, e.g. "1 hour", "60m" and "hourly" all mean 1h.
An unset interval keeps the scraper's default; an unsupported value is reported
and the timer is left unchanged.

Optional arguments:
  -h, --help        show this help message and exit
  --skroutz         Apply only the skroutz scraper interval
