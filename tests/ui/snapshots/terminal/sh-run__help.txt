Usage: run.sh [-h] [--quiet] [--debug] [--<target> ...]

Check prices for every registered target or only selected targets.
With no target flag, price-check every registered target.

Optional arguments:
  -h, --help        show this help message and exit
  --quiet           Run script with no console output
  --debug           Print the background log lines instead of the live panel
  --skroutz         Run exclusively the Skroutz scraper
  --amazon          Run exclusively the Amazon scraper
