Usage: schedule.sh [-h] [--debug] [--<target> ...]

Apply configured execution intervals to installed target timers.
Only registered targets are eligible; orphaned timers are skipped.
Supported intervals: 15m, 30m, 1h, 2h, 4h, 8h, 12h, 24h

Optional arguments:
  -h, --help        show this help message and exit
  --debug           show underlying command output
  --skroutz         Apply only the skroutz target interval
