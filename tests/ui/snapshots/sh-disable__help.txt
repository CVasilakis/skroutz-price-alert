Usage: disable.sh [-h] [--<target> ...]

Stop and disable installed scraper timer/service pairs.
Orphaned and partial unit pairs remain selectable for teardown.

Optional arguments:
  -h, --help        show this help message and exit
  --skroutz         Disable only the skroutz scraper
  --ghost           Disable only the ghost scraper
